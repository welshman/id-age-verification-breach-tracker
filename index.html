Why this exists

Passports, driver's licences, and national ID cards are increasingly uploaded to third-party services for KYC checks, age verification, and onboarding. Unlike a leaked password, you cannot reset your date of birth or passport number.

This site tracks publicly reported breaches of identity-verification and age-verification services and documents, so anyone can see which companies have had confirmed incidents and what data was exposed.

How it works

1. Public research

We track breaches reported by journalists, security researchers, and companies themselves.

2. Automated updates

A scheduled GitHub Actions workflow scans public feeds and opens new candidates for review.

3. Static & private

The whole site is static files on GitHub Pages, with no backend server or database.
